# 🚗 OTOMART — Marketplace & Platform Jual Beli Mobil

**OTOMART** adalah template situs web modern, responsif, dan interaktif untuk marketplace jual beli mobil baru maupun bekas. Platform ini dilengkapi dengan fitur pencarian katalog, kalkulator simulasi kredit, penaksir harga pasar mobil, serta modal autentikasi interaktif.

---

## ✨ Fitur Utama

- 🔍 **Katalog Mobil & Filter Interaktif**
  - Pencarian berdasarkan kata kunci (merek/model).
  - Filter kategori merek (*Toyota, Daihatsu, BMW, Mercedes-Benz, Audi*).
  - Filter tipe bodi (*SUV, MPV, Sedan, Hatchback, City Car*).
  - Pengurutan harga (Terendah / Tertinggi).

- 🧮 **Simulasi Kredit / Loan Calculator**
  - Memperhitungkan Uang Muka (DP), Bunga per tahun (%), dan Tenor (1–5 tahun).
  - Menampilkan estimasi cicilan bulanan, pokok pinjaman, dan total pembayaran secara real-time.

- 📊 **Penaksir Harga Mobil (Car Valuation)**
  - Mengestimasi nilai pasar mobil berdasarkan harga baru, tahun pembuatan, jarak tempuh (KM), dan kondisi fisik.

- 🔑 **Autentikasi & Modal Interaktif**
  - Form Login dan Registrasi interaktif dengan validasi data dasar.

- 📱 **Desain Responsif (Mobile-Friendly)**
  - Tampilan rapi di berbagai ukuran layar (Desktop, Tablet, dan Mobile) menggunakan CSS Grid & Flexbox.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Struktur halaman semantik.
- **CSS3** — Styling kustom, variabel CSS, Grid & Flexbox, serta efek responsif.
- **JavaScript (Vanilla JS)** — Logika kalkulator, filter dinamis, rendering data katalog, dan interaksi UI.
